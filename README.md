# 估值决策台

一个"算好位置、然后长期等待"的本地网页。每天打开点一下刷新，看一句话就知道今天该不该动手。

## 怎么用

1. 双击 **启动.bat**
2. 弹出一个黑窗口（别关），浏览器会自动打开 `http://127.0.0.1:8765/`
3. 每天回来点一次 **「刷新数据」**（约 1 秒，用当天缓存；想彻底重抓点 **「深度刷新」**，约 20~40 秒）
4. 看完想关：关掉那个黑窗口就行；下次再双击启动.bat

想直接看创业板，用这个地址：`http://127.0.0.1:8765/?tab=cyb`（可以存成书签）

## 页面上怎么看

| 位置 | 看什么 |
| --- | --- |
| 壹 · 今天该做什么 | **大字**就是结论：空仓等待 / 该动了 / 清仓走人。下面一行告诉你离两条线还差多少。右上把"空仓 / 已持仓"拨到自己的状态，建议会跟着变。 |
| 贰 · 估值标尺 | 一根尺子，从"深水"到"清仓"四档。指针停在哪格就该做哪档的事。 |
| 叁 · 点位与四条线 | 主图。圆点=历史上机械执行时的买点，方块=卖点。图例可以点掉不看的线。 |
| 肆 · 两个辅助视角 | 股债性价比、全收益 vs 债券。它们和估值不总是一致，**两个都指向便宜才是真便宜**。 |
| 伍 · 空仓的钱放哪 | 红利低波股息率到没到 5% 这条门槛。 |
| 陆 · 台账 | 历史大底当时多少估值；照这套规则做下来每一笔的收益（不含分红、不含手续费）。 |
| 柒 · 这些数字是什么意思 | 大白话解释四条线怎么算的、什么时候会失效。 |

## 四条线的算法

- **买入线** = 历史大底估值（沪深300 用 PE，创业板用 PB）的**中位数 × 1.10**
- **深入线** = 那个中位数本身
- **深水线** = 中位数 × 0.90
- **清仓线**：沪深300 用原文回测的 **PE 14.34**；创业板用 **PB 的 75% 分位**
- 线上的具体点位 = `估值阈值 × 当期每股盈利`，所以四条线会**随着企业盈利增长一年比一年高**，不是水平线。

底部是自动识别的：月度序列里，回撤 ≥ 20% 的局部最低点，且之后 18 个月内反弹 ≥ 10% 才算"确认的底"，进入中位数计算；最近的、还没反弹起来的不算。

## 想改参数

打开 `server.py`，最上面 `PARAMS` 就是全部可调项：

```python
PARAMS = {
    "hs300_buy_factor": 1.10,    # 买入线 = 底部中位数 × 1.10
    "hs300_sell_val": 14.34,     # 沪深300 清仓线（PE）
    "cyb_buy_factor": 1.10,
    "cyb_sell_quantile": 0.75,   # 创业板 清仓线（PB 分位）
    "dividend_threshold": 5.0,   # 红利低波股息率门槛 %
    "trough_dd": 0.20,           # 判定"底部"的最小回撤
    "trough_rebound": 0.10,      # 确认底部所需的最小反弹
}
```

改完保存，重启（关黑窗口再双击启动.bat）即可。页面顶部会把当前用的参数和分位数一起显示出来，方便你核对。

## 数据从哪来

| 数据 | 来源 |
| --- | --- |
| 沪深300 / 全收益 / 中证全债 点位 | 中证指数有限公司（官网接口） |
| 红利低波（H30269）市盈率、股息率 | 中证指数有限公司 |
| 沪深300 加权滚动 PE、创业板指加权 PB | 乐咕乐股 legulegu.com |
| 十年期国债收益率 | 经 akshare 取新浪/东财 |

原始数据落在 `data/raw/*.csv`，计算结果落在 `data/latest.json`。
**断网也能用**：抓不到就自动退回上一次的缓存，页面上会提示"显示的是上次结果"。

```
├─ 启动.bat            双击启动

```

## 注意

- 这个页面**不会**替你交易，也不会告诉你"明天涨跌"，它只会说"现在贵不贵、该不该动手"。
- 台账里的收益是**按月机械执行**的简化回测：不含分红、不含手续费、不含择时，只用来验证规则长什么样。
- 清仓线 14.34 是原文回测的经验值，不是天条；盈利增速长期下台阶时应该往下调。
- 所有结论仅供个人决策参考，不构成投资建议。
